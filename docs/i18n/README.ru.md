# Werkstadt

Werkstadt читает журналы сессий, которые Claude Code уже пишет на твоей машине в `~/.claude/projects/**/*.jsonl`, и превращает их в 3D-мир, по которому можно летать. Каждый проект становится планетой, островом или — на самом подробном уровне — городом: одна улица на сессию, одно здание на файл. Сервер написан на чистом Python, без зависимостей, и работает только на твоей собственной машине. Никакой сборки: правишь файл — перезагружаешь браузер. Лицензия Apache-2.0.

## Установка за 30 секунд

```
git clone https://github.com/beriki770-ship-it/werkstadt && cd werkstadt
python assets/fetch_assets.py --release
python server.py
```

Python 3.9 или новее, никакого `pip install`, никакой сборки. Вторая строка скачивает библиотеку текстур и моделей (около 100 МБ) из релиза; без неё мир всё равно откроется, просто без текстур.

## Приватность

Werkstadt работает целиком на твоей машине: Python-сервер, привязанный к `127.0.0.1`, и страница в браузере. Ничего не отправляется в сеть, нет ни аккаунта, ни какой-либо телеметрии. Журналы сессий только читаются и никогда не изменяются, не перемещаются и не удаляются. В них могут быть секреты и пути к файлам, так что относись к любому скриншоту или записи соответственно. С `"redact": true` в `config.json` (или флагом `--redact`) каждое имя проекта, сессии и путь к файлу заменяется на устойчивый псевдоним ещё до того, как покинет сервер.
