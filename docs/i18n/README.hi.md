# Werkstadt

Werkstadt आपके कंप्यूटर पर Claude Code द्वारा पहले से लिखी जा रही सेशन ट्रांसक्रिप्ट (`~/.claude/projects/**/*.jsonl`) को पढ़ती है, और उन्हें एक ऐसी 3D दुनिया के रूप में बनाती है जिसमें आप उड़ सकते हैं। हर प्रोजेक्ट एक ग्रह, एक द्वीप, या — सबसे बारीक स्तर पर — एक शहर बन जाता है: हर सेशन एक सड़क, हर फ़ाइल एक इमारत। सर्वर केवल Python की स्टैंडर्ड लाइब्रेरी से लिखा गया है, बिना किसी अतिरिक्त पैकेज के, और यह सिर्फ़ आपके अपने कंप्यूटर पर चलता है। कोई बिल्ड चरण नहीं है — फ़ाइल बदलिए, ब्राउज़र फिर से लोड कीजिए। लाइसेंस है Apache-2.0.

## 30 सेकंड में इंस्टॉल

```
git clone https://github.com/beriki770-ship-it/werkstadt && cd werkstadt
python assets/fetch_assets.py --release
python server.py
```

Python 3.9 या उससे नई ज़रूरत है, कोई `pip install` नहीं, कोई बिल्ड चरण नहीं। दूसरी लाइन रिलीज़ से करीब 100 MB की टेक्सचर और मॉडल लाइब्रेरी डाउनलोड करती है; इसे छोड़ भी दें तो दुनिया फिर भी खुल जाती है, बस बिना टेक्सचर के।

## प्राइवेसी

Werkstadt पूरी तरह आपके अपने कंप्यूटर पर चलती है: `127.0.0.1` से जुड़ा एक Python सर्वर, और एक ब्राउज़र पेज। कुछ भी कहीं अपलोड नहीं होता, न कोई अकाउंट है, न किसी तरह की टेलीमेट्री। सेशन ट्रांसक्रिप्ट सिर्फ़ पढ़ी जाती हैं, प्रोग्राम इन्हें कभी बदलता, हटाता या इधर-उधर नहीं करता। इनमें गोपनीय जानकारी और फ़ाइल पाथ हो सकते हैं, इसलिए किसी भी स्क्रीनशॉट या रिकॉर्डिंग को उसी हिसाब से संभालें। `config.json` में `"redact": true` सेट करने पर (या `--redact` फ़्लैग से), हर प्रोजेक्ट नाम, सेशन और फ़ाइल पाथ को सर्वर छोड़ने से पहले ही एक स्थिर छद्म नाम से बदल दिया जाता है।
