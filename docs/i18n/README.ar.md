# ويركشتات

يقرأ ويركشتات سجلات الجلسات التي يكتبها Claude Code أصلاً على جهازك، ويحوّلها إلى عالم ثلاثي الأبعاد يمكنك التحليق فيه. يتحول كل مشروع إلى كوكب، أو جزيرة، أو — في أدق مستوى — مدينة كاملة: شارع واحد لكل جلسة، ومبنى واحد لكل ملف. الخادم مكتوب بلغة بايثون فقط دون أي حزم إضافية، ويعمل على جهازك أنت فقط. لا توجد خطوة بناء: تعدّل ملفاً وتعيد تحميل المتصفح. الترخيص هو Apache 2.0.

## التثبيت في 30 ثانية

```
git clone https://github.com/beriki770-ship-it/werkstadt && cd werkstadt
python assets/fetch_assets.py --release
python server.py
```

يلزم إصدار بايثون 3.9 أو أحدث، بلا تثبيت حزم وبلا خطوة بناء. السطر الثاني يجلب مكتبة القوام والنماذج (حوالي 100 ميغابايت) من الإصدار المنشور؛ بدونها يفتح العالم كذلك، لكن دون قوام.

## الخصوصية

يعمل ويركشتات بالكامل على جهازك: خادم بايثون يستمع محلياً فقط، وصفحة متصفح. لا شيء يُرفع إلى الإنترنت، ولا يوجد حساب مستخدم ولا أي نوع من التتبع. سجلات الجلسات تُقرأ فقط، ولا يغيّرها البرنامج أو ينقلها أو يحذفها أبداً. قد تحتوي هذه السجلات على أسرار ومسارات ملفات، لذا يُفضّل التعامل مع أي لقطة شاشة أو تسجيل بهذا الاعتبار. هناك إعداد في ملف التهيئة يفعّل وضع "إخفاء الأسماء": يستبدل كل اسم مشروع وجلسة ومسار ملف بكنية ثابتة قبل أن تغادر البيانات الخادم أصلاً.
