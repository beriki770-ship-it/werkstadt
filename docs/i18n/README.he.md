# ורקשטאדט

ורקשטאדט קוראת את קובצי השיחה ש-Claude Code כבר כותבת על המחשב שלך, ומציירת מהן עולם תלת-ממדי שאפשר לטוס בתוכו. כל פרויקט הופך לכוכב לכת, לאי, או — בפירוט הגבוה ביותר — לעיר: רחוב אחד לכל שיחה, בניין אחד לכל קובץ. השרת כתוב בפייתון בלבד, בלי חבילות נוספות, ורץ אך ורק על המחשב שלך. אין שלב בנייה: עורכים קובץ, מרעננים את הדפדפן. הרישיון הוא Apache 2.0.

## התקנה תוך 30 שניות

```
git clone https://github.com/beriki770-ship-it/werkstadt && cd werkstadt
python assets/fetch_assets.py --release
python server.py
```

נדרש פייתון גרסה 3.9 ומעלה, בלי התקנת חבילות ובלי שלב בנייה. השורה האמצעית מורידה את ספריית הנכסים בגודל כ-100 מגה (טקסטורות, תמונות סביבה ומודלים) מתוך הגרסה המפורסמת; בלעדיה העולם עדיין נפתח, רק בלי טקסטורות.

## פרטיות

ורקשטאדט רצה כולה על המחשב שלך: שרת פייתון שמאזין רק לכתובת המקומית, ודף דפדפן. שום דבר לא עולה לרשת, אין חשבון משתמש ואין שום מעקב טלמטרי. קובצי השיחה נקראים בלבד ולעולם לא משתנים, זזים או נמחקים על ידי התוכנה. הם עלולים להכיל סודות ונתיבי קבצים, ולכן כדאי להתייחס לכל צילום מסך או הקלטה בהתאם. יש הגדרה בקובץ ההגדרות שמפעילה מצב "טשטוש שמות": היא מחליפה כל שם פרויקט, שיחה ונתיב קובץ בכינוי יציב לפני שהמידע יוצא מהשרת בכלל.
